# 一票通办 · One Shipment. One Space.

面向中小出口企业的单证预检与跨企业协同服务 —— 达飞杯首届高校创新大赛初赛参赛项目原型。

把一票海运出口业务的资料、版本与五方确认收进同一个协同空间：卖家、货代、船公司、地方物流、买家围绕同一票货物工作，资料变更生成新版本，确认与待办联动，流程分四阶段推进（建立货单 → 资料协同 → 运输反馈 → 交付确认）。

## 在线演示

启用 GitHub Pages 后可直接打开 `index.html` 演示（仓库 Settings → Pages → Deploy from a branch → main / root）。

演示要点（修复版逻辑）：

- 切换五方角色不重置数据，五方共用一份本票状态（保存在浏览器本地）
- 卖家确认版本后，确认待办自动完成；资料更新生成新版本并刷新确认待办
- 货代复核有前置锁定：卖家未确认当前版本时不可复核，并给出原因
- 船公司 / 地方物流 / 买家保存反馈后，对应待办自动完成，阶段自动推进
- 新建货单在演示模式本地可建，表单与当前货单隔离；日期可整段输入
- 单证预检输出差异清单（缺项 / 不一致 / 通过），差异可一键生成待办
- 服务购买：基础服务包 200 元/票（试点测试价），下单后服务状态可见
- 上传文件生成新版本；操作记录可真实导出；邀请码统一 30 位
